# AI Image Generation Project

## Description

This project generates images from text prompts using a
pre-trained Stable Diffusion model.

## Technologies

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion
- Streamlit
- Google Colab GPU

## Workflow

User enters a text prompt
        ↓
Streamlit interface
        ↓
Stable Diffusion model
        ↓
GPU inference
        ↓
Generated image
        ↓
Display / Save image
